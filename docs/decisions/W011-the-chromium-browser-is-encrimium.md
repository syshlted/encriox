# W11 — The Chromium browser is encrimium, and its package is `com.systemhalted.encrimium`

*2026-11-18 · accepted on the user's word ("OK let's use encrimium then"; "Let's also use the app id
`com.systemhalted.encrimium`"). **Amends W3**, which named it encrium. A knock-out search found nothing that blocks
the name (`docs/trademark-search.md`). Nothing of encrimium is built, and it has no repository yet.*

#### What the user decided

- **Not encrium**: `encrium.com` "appears to be owned by a French technical training academy". Its RDAP record hides
  its holder.
- **encrimium**, "since it keeps a true portmanteau": *encri* and *(chro)mium*.
- **Its package is `com.systemhalted.encrimium`.**

#### What was settled

1. **W3's rules still hold.** *encri* is whole in it, it ends as an element does, and it contains no Google mark:
   neither Chrome, Chromium nor Blink.
2. **The two names are made the same way**: *encri* joined to the end of the name of the browser each is forked from,
   encriox to *(f)ox* and encrimium to *(chro)mium*.
3. **The package is made as encriox's is** (W8): the product's name under `com.systemhalted`, permanent from the first
   build a user installs, and listed in encri-api's registry before the first release (encri D130). Nothing in encri
   or encri-api matches a package by prefix (W8), so the first characters it shares with encri's and encriox's take it
   for neither.
4. **encrimium's own first record settles the rest**, as W3 said: its repository, its decision prefix and its licence.
   W3's flag 1 proposed `encri-chromium/`, C and BSD-3-Clause, still unconfirmed. That record cites this one.

The nearest are DISCRIMIUM, a Spanish mark for medicines (class 5), and EncryM, a secure-messaging app from Canada
whose name is in no register TMview or Trademarkia holds. Read aloud, *en-CRIM-ee-um*, some may hear *crime*.

#### Rejected

- **encrium**: its domain, above.
- **encromium**, the user's first idea: *encri* is not whole in it, its *cromium* is a letter from Google's Chromium,
  and it is one letter from *encomium*, which autocorrect would make of it.
- **encridium, encrinite, encrilium and encrigen**, proposed with it: none says which engine it is built on.
